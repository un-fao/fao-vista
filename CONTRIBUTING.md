# Contributing

This repository publishes the code that produced the VISTA dataset. It is
maintained by FAO and is updated from FAO's working repository, so the files
under `core/`, `jobs/`, `tests/`, `data/calendars/`, `environment.yml` and
`config/quality_control.yaml` are not edited here directly.

- Report a bug or ask a question about the code by opening a
  [GitHub issue](https://github.com/un-fao/fao-vista/issues). Include the phase,
  the command you ran, the dekads selected and the full error message.
- Pull requests are welcome for discussion. An accepted change is applied in
  the working repository and appears here with the next update.
- Changes that would alter how the released dataset was produced are recorded
  in `CHANGELOG.md` as post-dating the release.

Contributors are expected to follow the
[FAO Code of Ethical Conduct](https://openknowledge.fao.org/items/7dc52196-d995-4ddf-97c6-fc8eef7a178f).
